# Эксперимент: Amethyst 1.19.1 со встроенным StikJIT

Состояние: исходники подготовлены. Сборка Xcode и проверка на физическом
iPhone ещё не подтверждены. Это не готовый проверенный IPA.

Изменения:

- Загрузка и запуск Minecraft ограничены Java Edition 1.19.1, Java 17.
- StikJIT запускается внутри отдельного AMJITHelper.appex в том же IPA.
- В меню JIT доступны встроенный помощник, внешний StikDebug и ожидание
  отладчика. Отказ встроенного метода не переключает метод автоматически.
- Pairing plist импортируется в Documents/StikJIT/pairingFile.plist;
  он не входит в исходники или IPA и не отправляется на GitHub.
- Временная копия pairing plist удаляется помощником после запроса.
- Существующий UniversalJIT26.js и handshake JavaLauncher сохранены.
- JavaLauncher по-прежнему проверяет/подготавливает исполняемую область до JVM.
- Успех открытия расширения сам по себе не считается включением JIT.

## Сборка

На GitHub: Actions → Personal Minecraft 1.19.1 with built-in JIT → Run workflow.
Workflow использует macOS, Xcode, JDK 8 для сборки самого лаунчера;
в итоговом IPA для игры остаётся только Java 17.

На Mac: установить cmake, make, ldid, xcodegen, JDK 8, задать JAVA_HOME
и выполнить `bash build-personal.sh`. JIT-библиотека закреплена на commit
32287268fa5824f9edce4cb359f5833ce0cf7b00. Её исходники и MPL-2.0 доступны
в https://github.com/StikDebug/StikJIT .

## Проверка на телефоне — обязательна перед заменой рабочего приложения

Сохранить копию Documents Amethyst через iTunes. Не удалять рабочий Amethyst
и StikDebug ради теста. IPA имеет исходный bundle ID Amethyst: установка с
тем же Apple ID может обновить существующее приложение, поэтому сначала
нужна резервная копия. Смену bundle ID и переустановку считать отдельной
операцией. При подписании сохранить AMJITHelper.appex и get-task-allow.

Условия: iOS 17.4+, включённый Developer Mode, актуальный pairing plist,
подключённый LocalDevVPN. LocalDevVPN пока остаётся отдельным приложением.
Расширение может потребовать отдельный App ID при бесплатной подписи;
сама интеграция не снимает ограничения Apple на подпись и срок 7 дней.

Проверить: импорт pairing, Prepare, Play 1.19.1, мир и сервер, холодный запуск,
повтор после перезагрузки телефона, неверный pairing, выключенный VPN,
отмену/таймаут, очистку DDI и возврат к внешнему StikDebug. Не считать
успех компиляции доказательством совместимости с iOS 27.

## Общий лаунчер

AMBuiltInJIT — отдельный координатор, JITHelper — отдельный target. Их можно
перенести в будущую оболочку вместе с Java-движком, заменив идентификаторы
расширения и маршрутизацию запуска. GTA V и GTA IV потребуют своей отдельной
интеграции; готовые IPA нельзя просто вложить друг в друга. Код общего
лаунчера пока не создан.
